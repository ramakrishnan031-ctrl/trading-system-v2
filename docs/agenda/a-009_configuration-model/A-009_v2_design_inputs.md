## 6. Broker and exchange values from official sources (RAMA Q13; VP-49)
- RAMA (Q13, verbatim): "Actually these configured runtime broker/API has details set after searching official Zerodha website only (Not set random numbers), So I guess the numbers are remains same as of now, So during implementation follow same process like Search Zerodha Broker>Set numbers for system [Not random, Not by assumption] - take a note of it in 'Manual' carefully".

- LEGACY (checked 2026-10-08): the equity charges match Zerodha's current page except the NSE transaction charge (legacy 0.00297%, current 0.00307%); a CNC SELL brokerage statement in the legacy file does not align directly with the zero delivery rate, and the actual legacy treatment of CNC-sell charges is UNKNOWN (calculator not inspected, no contract notes here); the never-traded F&O rates differ; the GTT cap (50 against 500) and the quote rate (3 per second against 1) were also out of date (A-006, A-007).
- CURRENT EXTERNAL BROKER FACT (zerodha.com/charges, checked 2026-10-08): equity intraday brokerage 0.03% or Rs 20 per order, whichever is lower; equity delivery brokerage zero; STT 0.025% on intraday sells and 0.1% on delivery buys and sells; NSE transaction charge 0.00307%; GST 18% on brokerage, SEBI and transaction charges; SEBI Rs 10 per crore; stamp duty 0.003% on intraday buys and 0.015% on delivery buys.
- CURRENT EXTERNAL BROKER FACT (Kite Connect v3 margins documentation, checked 2026-10-08): these are broker-side CALCULATION APIs for the order(s) in the request. POST /margins/orders "Calculates margins for each order considering the existing positions and open orders"; its response includes leverage ("Margin leverage allowed for the trade") and a charges breakdown. POST /charges/orders "Calculates order-wise charges for orderbook" (the virtual contract note: brokerage, STT, exchange transaction charge, SEBI fee, stamp duty and GST per order); it takes an executed average price, and the order ID "can be any random string to calculate charges for an imaginary order".
- CURRENT EXTERNAL BROKER FACT (Zerodha, checked 2026-10-08): equity charges follow the resulting trades, not the product chosen: "Charges are displayed based on trades and not the product type (MIS or CNC)" and "The FIFO (First In, First Out) method is used to determine intraday and delivery trades" (Z-Connect, 3-Jul-2023); delivery charges are shown by default whichever product was used, and intraday charges only after a same-day square-off (support article).
- These external facts do not prove what the legacy system was charged.
- CLAUDE CONSIDERATIONS (F, G, L, M; none decided):
  - Each broker or exchange value carries its source page and the date it was checked, and a review interval; a pre-market check reminds when a check date is too old. A changed value is a configuration change (section 3).
  - Use broker APIs for broker-calculated order margin and charge references where available (/margins/orders, /charges/orders), and broker state endpoints for actual live account state (funds, positions, orders); neither calculation API is the account's truth for all runtime state (VP-35). Tick and lot come from the instrument dump (VP-28). Static rates remain only as an estimate and a cross-check.
  - Charges depend on the resulting trades (FIFO), not only on the product sent, so a charge estimate made at order time can differ from the final contract note; reconcile computed charges with the broker's contract note (VP-40).
