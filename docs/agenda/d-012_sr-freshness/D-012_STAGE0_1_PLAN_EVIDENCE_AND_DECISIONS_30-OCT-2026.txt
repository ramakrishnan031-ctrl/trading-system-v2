- Q1 ("Freshness"): D-012 S&R freshness. D-011 fixed its starting definition: "How recent or stale the historical
  price behaviour supporting an S&R reference is." Should V2 show freshness for each S&R reference? Options: "Yes, as
  information (Recommended)": Shown with the reference, with no trading authority; how later topics use it is theirs
  to decide, as for strength.; "No freshness shown": References carry no freshness.; "Decide later in design": Keep
  D-012 open; your answers stay raw input.
- Q2 ("Expiry"): Does an S&R reference ever stop being a reference because it is old? You wrote that historical S&R
  points are "fixed/unchangeable" (D-010 Q9). [The question cited Rama's D-010 Q9 words, which answered whether zones
  are common or strategy-specific (E12-04); using them for expiry was Claude's reading.] Options: "No automatic expiry
  (Recommended)": An old reference stays a reference; freshness only describes how recent its support is. How far back
  history is read (your 3 and 5 years) stays with D-007 and the data topics.; "Old references expire": References whose
  last reaction is older than a limit set in design are dropped.; "Decide later in design": Keep it open.
- Q3 ("Evidence"; more than one may be ticked): Which kinds of evidence may freshness rest on? Kinds only: how each
  is measured is NOT decided here. Options: "Time since last reaction": How long ago price last reacted at the
  reference (calendar time).; "Candles since last reaction": How many candles have passed since then; which
  timeframe waits for D-007.; "Crossed since last reaction": Whether price has moved through the reference since its
  last reaction.; "Recent re-tests": Whether price has come back to the reference recently.
- Q4 ("Display"): How should freshness be shown for a reference? Options: "Evidence plus a label (Recommended)": Show
  the evidence (for example the last reaction's date) and a simple label such as fresh / aging / stale; how the label
  is set is left to design.; "Evidence only": Show the dates and counts; no label.; "Label only": Show only a fresh /
  aging / stale label.; "Decide later in design": Keep it open.
