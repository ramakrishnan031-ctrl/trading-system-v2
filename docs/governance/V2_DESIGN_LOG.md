## 5. WORKING RULES

- W-1 Two layers. A topic manual records legacy fact only. V2 directions are PROPOSED in section 3 and become DR rows when decided. (ChatGPT's governing rule for A-001, adopted 2026-10-05.)
- W-2 File-save rule (permanent, set by Rama 2026-10-05; revised by Rama 2026-10-19, DR-041). Once all the files of a step are final and ready for storage, the reply ends with a SAVE list: each file, its folder, and whether it is new or replaces an existing one. Until then, replies do not list where files are to be stored (Rama, 19-Oct: "why? save chat space"). From 2026-10-05 to 2026-10-18, every reply that involved a file ended with a SAVE list.
- W-4 Approval rule (permanent, set by Rama 2026-10-05, DR-017). Once ChatGPT has reviewed a topic and its points are applied, Claude prepares the final storage-ready files (FROZEN status, register rows, commit/push commands) without a separate approval step. Exception proposed by Claude: if ChatGPT's review leaves a question for Rama or disagrees with Claude, Claude asks Rama first.
- W-5 Current external facts (adopted 2026-10-06 from ChatGPT's A-006 review, point 1). A current broker, exchange or regulator rule is labelled CURRENT EXTERNAL BROKER FACT with the date it was checked, and is never presented as evidence of legacy behaviour. Manuals frozen before A-006 keep their EXTERNAL CONTEXT label.
- W-6 Topic boundaries (adopted 2026-10-06 from ChatGPT's A-006 review, point 7). A topic does not settle questions that belong to another topic; it records them as PROPOSED inputs carried to that topic (for example A-006 to A-007 for product semantics, to G/H for order construction and exits, to A-010/M-005 for the token lifecycle). A ChatGPT review alone never turns a V2 proposal into a decision.
- W-7 Evidence is claim-specific (adopted 2026-10-10 from ChatGPT's final B-001 review, point 2; DR-036): "Evidence is claim-specific, not governed by one universal ranking. Repository source establishes what the named baseline defines; dated host records establish only the states/events they record; testing captures establish testing-VM state only; supplied records and user recollection retain their own provenance and limitations. When evidence conflicts, state the conflict and assess source fitness for the specific claim. Do not use a repository declaration alone to infer historical installation or final host state." The "Source priority" lines in the frozen A-005 to A-011 manuals are read under this rule, without errata; B-001's was corrected by erratum E-1. Manuals from B-002 on state this rule instead of a ranking.
- W-8 Commit messages and records (set by Rama 2026-10-10; DR-036). Commit messages end with the Co-Authored-By line only, without a Claude session link, and no session link is written into a project record. Earlier commit messages and the stored Section B handover note stay as they are (the repository is private, and a session is visible to others only if its owner shares it).
