2. PROCESS EXCEPTION (disclosed)
- While adding the root README to the sparse set, the pattern "README.md" was entered without a leading slash. In non-cone mode it matched README.md in every directory, so one never-open blob (docs/web_claude/README.md) was fetched into the local object store and the working tree. sensitive_check reported 1.
- Its contents were not opened, read, printed or searched; only its path and blob ID were identified.
- Fix: pattern changed to "/README.md"; sparse set reapplied (the never-open directory left the working tree); the promisor pack holding that blob (7 README blobs, fetched in the same call) was deleted from the local object store; sensitive_check rerun: 0.
- Lesson for the design log (proposed): always anchor non-cone sparse patterns with a leading slash.
