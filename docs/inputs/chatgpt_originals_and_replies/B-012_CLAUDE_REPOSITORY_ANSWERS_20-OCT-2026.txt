B12-C2. PARTLY ESTABLISHED.
- SOURCE (mechanism): the kernel drops flock and reclaims the socket when the process dies by any means, so a crash, SIGKILL, OOM kill or power loss leaves no lock that blocks the next start (docstring 15-24, 91-93; release docstring 224-226). The PID in the file is informational only (no branch on it).
- INTERP: the release in main()'s finally runs when _main_locked returns. If the non-daemon HARD_KILL flatten worker outlived B-011's 15 s drain, the process is still alive after the lock is released. A second instance started by hand in that window would not be refused. systemd and the watcher would not start one, because the unit is still active. Not tested; conditional.
- INTERP (B-001 section 7.3): PrivateTmp=true gives the service its own /tmp, so an instance started outside the unit meets only the port layer.
- SOURCE: check_port_available (241-257) exists but main.py does not call it (search of main.py).
B12-C3. PARTLY ESTABLISHED.
- TEST tests/unit/test_instance_lock.py (not run): second concurrent instance refused (139); restart after crash not blocked (150); restart after clean exit (191); live unrelated PID in file does not block (198); port conflict releases the file lock (241); stale dead PID and garbage file accepted (282, 289); release idempotent (316).
