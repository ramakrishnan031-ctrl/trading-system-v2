3. NEW NAMED TERMS (needed by C1, C2, G3 and rule P)
==============================================================================================================================
- T10, a SQL reference to the signals table: \b(FROM|JOIN)\s+signals\b
- T11, a SQL table reference, any table: \b(FROM|JOIN)\s+[a-z_][a-z0-9_]*
- Both case-sensitive: the SQL keyword in upper case, the table name in lower case. They do not match a Python import
  (from signals.x import y), prose in lower case, a dictionary key ("signals": 0) or, for T10, a longer name such as
  signals_archive.
- FR, a consumer line: \[\s*["'](strategy|scanner)["']\s*\]|\.get\(\s*["'](strategy|scanner)["'] - a line that reads a
  "strategy" or "scanner" field of a row or entry. The driver applies FR only to lines already printed; it is never searched.
  On Stage 1's printed lines FR selects 53 lines: replay_signals.py 3, db_reader.py 27, scanner_attribution.py 13,
  strategy_ranking.py 8, strategy_health.py 1, compute_strategy_metrics.py 1.
- Known limits, to be stated with the results: SQL with lower-case keywords, a keyword and its table name split across lines,
  or a table name built at run time is not matched; a docstring with an upper-case "FROM signals" would match.

5. RULE P (pairing reads; fixed in advance, applied by the driver)
==============================================================================================================================
- Consumer lines: the lines printed by Stage 1 reads 007, 009, 011, 013, 014 and 017 and by G1 that match FR. Read 010 is
  excluded (D-1).
- For a consumer line L in a file with G3 output, Q is the highest G3 line number not above L.
- Read the range Q:L only if Q's printed line matches T10 (a query on the signals table), L - Q is at most 30, and some line
  of Q:L has not yet been printed by an F read or an earlier P read of that file. One read per Q, from Q to the highest such
  L; at most 31 lines.
- Otherwise no read. The evidence then gives, from the grep lines, the nearest query's table and its distance (FACT for the
  lines; the pairing is INTERPRETATION), or "no SQL reference above L", and the line's source stays NOT ESTABLISHED.
- Caps: 6 P reads per file and 250 P lines in all, taken in the order of s_1b and then by line; candidates beyond a cap are
  recorded, not read.
- After D-1, the rule tests the authorised condition itself (a SQL reference to the signals table), not a word. Before W3 it
  is tested on synthetic input with a true case and the likely false positives: a Python import, lower-case prose, a
  dictionary key "signals", signals_archive, a nearer query on another table, a gap of 31 lines, a range already printed, a
  cap reached.
