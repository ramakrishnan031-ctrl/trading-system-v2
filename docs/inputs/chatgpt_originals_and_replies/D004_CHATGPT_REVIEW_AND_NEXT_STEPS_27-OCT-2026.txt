F. Invalid and inconsistent data: missing quote/candles, empty results, stale/delayed data, duplicate/out-of-order candles, symbol-key/case mismatch, API errors, incomplete OHLCV, zero/negative values and numeric anomalies. Report only actual handling demonstrated by source; else UNKNOWN.
