SOURCE RECONCILIATION
1. Production config explicitly states HH:MM values are interpreted as IST.
2. Production config distinguishes entry_end (15:00) from eod_entry_cutoff
   (15:15); they are separate mechanisms.
3. Production config identifies 15:09 as the primary MIS protective deadline.
4. Production config identifies 15:17 as the EOD accounting/emergency
   backstop, not the primary MIS square-off.
5. Production config identifies 17:35 as service_window_end.
6. Production main.py contains a 15:15 force-close callback and states that
   pending entry orders are cancelled; its notification states EOD square-off
   closes INTRADAY positions at 15:17 while DELIVERY is carried.
7. Production main.py contains a 14:45 EOD pre-alert; this is an alert time,
   not evidence that entry_end or eod_entry_cutoff equals 14:45.
8. Production config states entry_start=10:00 is a global floor over
   per-strategy windows.
9. Production config contains signal_queue expiry_sec=600, but this alone
   does not prove the exact fate of every out-of-window signal.
10. Production config contains IST clock/skew controls; main.py uses the
    IST time authority in timing-sensitive code.
