1. FINAL A-004 CONCLUSION
============================================================

FROZEN LEGACY SCOPE:

The legacy trading system's documented trading baseline was NSE equity
trading through externally generated Chartink signals, using Zerodha as the
execution broker. Both Intraday/MIS and Delivery/CNC behavior were configured,
and Delivery/CNC was historically active according to the user's direct
contract-note evidence.

The repository evidence establishes that the instrument-reference pipeline
was NOT simply "all Zerodha instruments". Production builds
config/instruments.csv from an NSE security master restricted to equity
series, sector/index reference data, F&O-symbol reference data, and the
Zerodha Kite instrument dump. The resulting file is loaded at startup and
used by downstream components.

Therefore the previous user answer "all Zerodha NSE equity instruments" is
NOT retained as an exact technical fact. The safer historical classification
is:

"Production used a centrally built NSE-equity-oriented instrument reference
file; the exact historically eligible trading universe is not established
as literally every Zerodha NSE equity instrument."

A Production-level excluded_symbols list existed and was rejected at the
webhook edge. This directly contradicts the original answer "No blacklist".
The correct legacy record is that explicit symbol exclusions existed.

The requested future V2 preference to remove this type of static blacklist
is recorded separately and does not change the legacy manual.
