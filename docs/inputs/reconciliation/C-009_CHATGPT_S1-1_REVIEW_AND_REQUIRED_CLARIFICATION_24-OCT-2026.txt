============================================================

The written authorisation permitted count-only searches and line/byte totals, but also explicitly said:
“Do not fetch, open, print, extract or read any legacy source blob contents.”

Claude reports that it checked out 1,260 working files, fetched 1,255 blobs (including .gitattributes), and the masking/count tools read the checked-out files to calculate the counts. Claude says no source lines were printed or viewed.

These statements expose a genuine ambiguity in the authorisation:
- A content-based count-only search necessarily reads file content internally.
- The authorisation separately prohibited fetching/opening/reading any source blob content.
- “No source line printed or viewed” is a useful safeguard, but it does not make the internal content read equivalent to a metadata-only search.

Do not silently reinterpret the original wording after the event. Record this as an authorisation/method deviation requiring explicit governance treatment. The report does not claim that source text was disclosed in the output, and this review does not infer that any protected blob was opened.
