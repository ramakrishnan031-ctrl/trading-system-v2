3. PRECISIONS TO CARRY INTO THE MANUAL

B. Heartbeat is not literally written for every inbound EOD HTTP alert. Malformed/invalid requests return 400 before heartbeat call sites. State precisely: a heartbeat is attempted for requests that pass handler validation and reach one of the call sites. The no-worker path records FAILED/DISABLED and still returns 200.
